## 🎯 About

A collection of **Data Structures & Algorithms** concepts with clean, commented code, organized topic by topic. Built for learning, revision, and interview preparation.

Each topic includes:

- **Concept notes** on what it is and when to use it
- **Code implementations** that are readable and commented
- **Complexity analysis** for time and space
- **Practice problems** of classic and interview style

> Language used: **<!-- C++ / Java / Python / JavaScript -->**

## 🧠 Topics Covered

| Topic | Key Concepts |
|-------|--------------|
| Arrays | Two pointers, sliding window, prefix sum |
| Strings | Pattern matching, palindromes, anagrams |
| Recursion | Base case, call stack, subsets, permutations |
| Searching & Sorting | Binary search, merge sort, quick sort |
| Linked List | Singly/doubly, reversal, cycle detection |
| Stack & Queue | Monotonic stack, deque, expression evaluation |
| Trees | Traversals, BST, height, LCA |
| Graphs | BFS, DFS, shortest path, topological sort |
| Hashing | HashMap/HashSet, frequency counting |
| Dynamic Programming | Memoization, tabulation, knapsack, LIS |
| Greedy | Interval scheduling, activity selection |
| Backtracking | N-Queens, sudoku, combinations |

## 📈 How to Use This Repo

1. Pick a topic folder and read the concept notes first.
2. Try solving the problem yourself before looking at the code.
3. Compare your approach with the solution and its complexity.
4. Revisit topics regularly before interviews.
