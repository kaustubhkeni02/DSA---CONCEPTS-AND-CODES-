## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/kaustubhkeni02/DSA---CONCEPTS-AND-CODES-.git
cd DSA---CONCEPTS-AND-CODES-
```

```bash
# C++
g++ filename.cpp -o output && ./output

# Java
javac Filename.java && java Filename

# Python
python filename.py
```

> ✏️ Keep only the command for the language you use.
